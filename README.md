# Skills

A skills by [Aziz](https://x.com/iAziz786)

## Install

Install globally, so every project gets the skills:

```bash
npx skills add iAziz786/skills -g
```

Drop `-g` to install into the current project only. The CLI prompts for which skills and which agents to target.

Install one skill non-interactively:

```bash
npx skills add iAziz786/skills --skill concise -g -y
```

List what the repo offers without installing:

```bash
npx skills add iAziz786/skills --list
```

Update installed skills:

```bash
npx skills update -g
```

CLI reference: https://skills.sh/docs/cli

## Skills

| Skill | What it does |
| --- | --- |
| `concise` | More comprehensive and concise answers; every word must prove its worth for user understanding. |
| `proposal` | Drafts a pragmatic, low-level fix proposal before code is written. |
| `search` | Web search via CLI providers: Exa, Firecrawl, Tavily, Serp API. |
